# Transformation: Georgia Tech IMU → Axilles exo IMU

For each segment (foot, shank) there is a rotation **R** and a lever arm **d**:

```
gyro_exo = R · gyro_gt
acc_exo  = R · acc_gt + α × d + ω × (ω × d)        ω = gyro_exo,  α = dω/dt
```

- **`d`:** the exo IMU position minus the Georgia Tech IMU position, in the output
  frame [m]. The accelerometer needs it because a different point on the same segment
  accelerates differently. The gyroscope only needs `R`.
- **`T_gt_in_exo_4x4`:** the same thing as a pose matrix, `[R, −d; 0 0 0 1]`.

| Folder | Output axes | Use when |
|---|---|---|
| `exo_frame/` | exo frame: x forward, y left, z up (standing) | comparing, plotting, physical interpretation |
| `imu_raw_frame/` | your exo IMUs' raw sensor axes (BNO085 output, Sept 11 mounting) | feeding Georgia Tech data to a model that takes raw exo IMU readings |

The two are related by `R_raw = Cᵀ R_exo`, `d_raw = Cᵀ d_exo`, where
`C = R_exo_frame_from_exo_sensor` in `exo_imu_calibration.json`.

Raw IMU axes (Sept 11 mounting):

| Raw axis | Shank IMU | Foot IMU |
|---|---|---|
| x | up | up, tilted ~28° back |
| y | backward | back and down |
| z | right | right |

## Files (in each folder)

| File | What it contains |
|---|---|
| `transform_version1_average.json` | **Version 1:** one R, d, T per segment, from the average of all 22 subjects |
| `transform_version2_per_subject.json` | **Version 2:** each subject's own R, d, T, with the positions in the segment frame and the encoder position |
| `transform_version2_per_subject.csv` | The same as a table (first row block = average) |
| `exo_imu_calibration.json` | Your exo IMUs' rotation into the exo frame for each session (Sept 11, Apr 4), plus stride statistics |

Units: Georgia Tech accelerometer in g (multiply by 9.80665), gyro in rad/s. The
foot/shank accelerometer sign is +1 for all subjects.

## Applying it

```python
import json, numpy as np
from imu_locator.exo_transform import Transform
t = json.load(open("3_transformation_matrices/imu_raw_frame/transform_version1_average.json"))["shank"]
T = Transform(R=np.array(t["R_gt_sensor_to_exo"]), r_gt=np.zeros(3), r_exo=np.zeros(3),
              d_override=np.array(t["lever_arm_d_m"]))
acc_exo, gyro_exo = T.apply(gt_accel_in_g, gt_gyro_rad_s, fs=200)   # -> m/s², rad/s
```

The ready-made transformed dataset is in `5_data/` (regenerated by script, not in Git).

## Important

`axilles_jetson/exo_frame_calibration.json` (the older rotation-only fit against AB06)
has its **shank rotation flipped by about 170°**: the shank swing comes out as −7.6 rad/s
where your exo IMU reads +6 rad/s. Its foot rotation agrees with these transforms within
5.6°. Use the files here instead.
